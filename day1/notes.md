## What I Covered

### 🌐 Internet Basics
- **HTTP** — HyperText Transfer Protocol. Browser sends a request → Server sends a response.
- **HTTPS** — Secure version of HTTP. Uses SSL/TLS encryption.
- **DNS** — Domain Name System. Converts `google.com` → IP address like `142.250.190.46`.
- **Browser-Server Flow:** Browser → DNS → Server → HTML/CSS/JS back to Browser.
